# DSH Agent App Icon Prompt

## 目标
生成一张可直接用作 Android 应用图标的 1:1 图标素材，风格现代、简洁、可缩放，适合作为 DSH Agent（DeepSeek Harness 监控台）的品牌标识。

## 核心意象
- 雷达扫描 / 监控台 / 智能 Agent 信号
- 简洁科技感，不要太写实，也不要太幼稚

## 风格
- 现代扁平 + 轻微渐变，接近 Google Material / Adaptive Icon 风格
- 强轮廓、少细节，保证小尺寸可识别
- 圆角方形构图，主体居中，预留 10% 安全边距

## 配色
- 主色：blue grey / slate 蓝灰
- 辅助：青色或淡蓝高光
- 背景：同色系深色渐变，避免纯黑纯白

## 必含元素
- 一个抽象的“雷达波”或“信号扫描”图形
- 一个微型“Agent”节点/光点

## 禁含元素
- 英文文字、复杂纹理、人脸、照片级光影

## 输出
- 1:1 正方形
- 圆角方形图标
- 透明背景版本可选，但第一张优先 opaque 圆角方形底
